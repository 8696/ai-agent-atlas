# 04-a · UI · 总则、布局与菜单

> UI 规格。**写代码前先对这份**；实现与规格冲突时以本文为准，改规格要同步改代码。

## 4.1 设计总则

- **Ant Design 6** 优先：能用组件就不自己画
- **token 优先**：颜色 / 间距 / 圆角一律用 `theme.useToken()`，
  ⚠️ **不写死浅色**（深色模式下写死的浅色 = 看不见）
- 页面结构 = **侧栏 + 顶栏 + 内容区**；内容区最大宽度 1200px 居中
- 主色沿用品牌色；危险色只用于「删除 / 拒绝 / 超预算」
- 图标用 `@ant-design/icons`
- 空状态要有：一句说明 + 一个明确的下一步动作（按钮）

## 4.2 整体布局

```
┌───────────────┬──────────────────────────────────────────────────┐
│               │  顶栏：页面标题        [预算告警条]  🌙  👤      │
│   侧栏 240px  ├──────────────────────────────────────────────────┤
│               │                                                  │
│  ◆ 新对话     │                                                  │
│  ─ 历史会话   │                 内容区（最大 1200px）            │
│    · 会话 A   │                                                  │
│    · 会话 B   │                                                  │
│  ─────────    │                                                  │
│  ⚙ 设置       │                                                  │
│  📊 观测       │                                                  │
│               │                                                  │
│  [折叠按钮]   │                                                  │
└───────────────┴──────────────────────────────────────────────────┘
```

| 元素     | 规格                                                              |
| -------- | ----------------------------------------------------------------- |
| 侧栏宽   | 240px（展开）/ 64px（折叠，只留图标）                             |
| 顶栏高   | 56px                                                              |
| 内容区内边距 | 24px（窄屏 16px）                                              |
| 卡片圆角 | 8px                                                              |
| 页面留白 | 内容区顶部 24px                                                  |

⚠️ **窄屏（< 992px）自动折叠侧栏**，且要有手动展开按钮
（折叠了打不开 = 功能不可达）。

## 4.3 菜单树

```
◆ 新对话                       → /chat

── 历史会话 ──                  → /sessions
   · 会话列表（按最近活跃倒序）
   · ★ 只看收藏（开关）
   · 🔍 搜索会话

── 设置 ──                      → /settings/*
   · 模型                       → /settings/models
   · 提示词                     → /settings/prompts
   · 工具                       → /settings/tools
   · Skill                      → /settings/skills
   · MCP                        → /settings/mcp
   · 记忆                       → /settings/memory
   · 通用配置                   → /settings/general

── 观测 ──                      → /traces · /cost
   · 调用链路                   → /traces
   · 成本分析                   → /cost
```

> ⚠️ **分组只有 3 组**（对话 / 设置 / 观测）——
> 本地单用户项目不需要 7 组菜单，组多了反而找不到。

## 4.4 顶栏

| 元素       | 行为                                                                |
| ---------- | ------------------------------------------------------------------- |
| 页面标题   | 当前页面名（随路由变）                                              |
| 预算告警条 | `cost_logs` 本月用量 ≥ 预算 × `warn_ratio` 时出现；显示进度条 + 百分比 |
| 主题按钮   | ☀ / 🌙 切换，持久化到 `localStorage`                                |
| 用户菜单   | 显示邮箱 → 改密码 → 退出登录                                       |

⚠️ **预算告警条不能挡住内容**：用 `Alert` 的可关闭样式，
或固定在内容区顶部而不是浮在顶栏上。

## 4.5 主题与深色模式

- token 三层：**品牌 / 浅色 / 深色**
  ⚠️ **背景色不能共用一份** —— 共用则切暗色仍是白底
- 切换按钮挂在 `AppLayout`（登录页与设置页共用同一份骨架）
- 未设置过时跟随系统 `prefers-color-scheme`
- `<html data-theme>` 与 token 联动；滚动条按它分深浅两套
- ⚠️ **首屏不能闪白底**：`index.html` 里先放一段内联样式定住背景色

## 4.6 通用状态

每个列表页都要有这四种状态：

| 状态     | 表现                                     |
| -------- | ---------------------------------------- |
| 加载中   | `Skeleton` / `Spin`                     |
| 空       | 一句说明 + 一个行动按钮                 |
| 出错     | 错误文案 + 「重试」按钮（⚠️ 不显示堆栈） |
| 正常     | 表格 / 列表                             |

## 4.7 交互细则

| 场景           | 规定                                                             |
| -------------- | ---------------------------------------------------------------- |
| 破坏性操作     | `Popconfirm` 二次确认；删除不可撤销的要在文案里说明             |
| 提交中         | 按钮 `loading` + 禁用重复提交                                     |
| 长任务         | 显示进度 / 状态轮询（⚠️ 轮询闭包要拿最新 state，否则拿到旧值） |
| 表单校验       | 提交时校验 + 失焦校验；错误文案指到字段                         |
| 复制           | 复制成功给 `message.success` 反馈                                |
| 表格列宽       | 固定操作列在右侧；窄屏横向滚动                                   |
| 批量操作       | 表头「全选」必须真的能用（⚠️ 容易做成死按钮）                   |

## 4.8 无障碍与可用性底线

- 所有可点元素有 `title` / `aria-label`
- 焦点态可见（不要 `outline: none` 了事）
- 颜色不是唯一信息载体（状态要有图标或文字）
- 键盘可达：Tab 顺序合理，Esc 关闭弹层
