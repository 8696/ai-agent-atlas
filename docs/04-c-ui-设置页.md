# 04-c · UI · 设置页

> UI 规格。写代码前先对这份。

## 4.1 模型配置 `/settings/models`

| 区域         | 内容                                                            |
| ------------ | --------------------------------------------------------------- |
| 列表         | 名称 · 供应商 · 模型标识 · 用途 · 启用 · 默认 · 操作           |
| 新建 / 编辑  | 抽屉：名称 · 供应商 · `base_url` · API Key · 模型标识 · 用途 · 启用 · 是否默认 · 备用模型 · 输出上限 · 温度 · 思考预算 |
| API Key 字段 | 密码框；编辑时**留空 = 保持原样**；保存后只显示掩码             |
| 用途下拉     | `chat` / `memory` / `summary` / `embedding`                    |
| 操作         | 编辑 · 设默认 · 启用/停用 · 删除                                |

⚠️ **`base_url` 的 SSRF 校验**：保存失败时错误要指到字段，并说明原因
（「不能指向内网地址」），而不是笼统的「保存失败」。
⚠️ **没有模型时的空状态**：明确告诉用户「还没配置模型」+ 一个「去配置」按钮，
⚠️ **不要显示成错误页**。

## 4.2 提示词 `/settings/prompts`

| 区域       | 内容                                                              |
| ---------- | ----------------------------------------------------------------- |
| 左列       | 提示词名称列表（`system` / `tool` / `memory` / `summary`）         |
| 右列       | 版本列表（版本号 · 状态 · 更新时间）+ 编辑区                      |
| 编辑区     | Markdown 文本域 + 占位符提示（`{{tools}}` `{{memories}}` …）       |
| 动作       | 保存草稿 · 发布 · 回滚                                             |
| 生效标记   | 当前生效的版本要有明确标记                                        |

⚠️ **占位符提示**：编辑区旁边列出生效的占位符与说明。
⚠️ **「发布」是不可逆的状态变更** → `Popconfirm`。
⚠️ **单版本时也要显示底部操作条**（⚠️ 常见 bug：只有一个版本时底栏不渲染）。

## 4.3 工具管理 `/settings/tools`

| 区域     | 内容                                                             |
| -------- | ---------------------------------------------------------------- |
| 列表     | 工具名 · 来源（内置/Skill/MCP）· 描述 · 敏感档 · 启用 · 操作    |
| 描述编辑 | 行内可改（⚠️ 改完立即生效，下一轮就能看出模型调不调它）          |
| 敏感档   | `low` / `normal` / `high`，可改                                  |
| 启停     | 开关；停用的工具不进模型工具池                                    |
| 分组     | 按来源分组折叠                                                    |

⚠️ **「描述」列要能看全**：长描述截断 + hover 展开，
⚠️ **不要放在一个看不见的地方** —— 它是「调教模型」的主要抓手。

## 4.4 Skill 管理 `/settings/skills`

| 区域     | 内容                                                          |
| -------- | ------------------------------------------------------------- |
| 列表     | 名称 · 描述（触发条件）· 版本 · 来源目录 · 操作               |
| 安装     | 上传 `.zip` 或选择本地目录                                     |
| 详情     | 显示 `SKILL.md` 的 frontmatter 与正文（只读预览）             |
| 操作     | 启用/停用 · 编辑描述 · 卸载                                    |

⚠️ **安装前必须提示**：「技能包里的脚本可以在本机执行任意代码」。
⚠️ **Skill 自带脚本的工具默认是 `high` 敏感档**（走确认闸）。

## 4.5 MCP 服务器 `/settings/mcp`（P2）

| 区域     | 内容                                                          |
| -------- | ------------------------------------------------------------- |
| 列表     | 名称 · 传输 · 地址/命令 · 状态 · 工具数 · 策略 · 操作         |
| 新建     | 名称 · 传输（stdio/sse/http）· 命令与参数 / URL · 环境变量     |
| 连接状态 | `disconnected` / `connected` / `error` + 错误原因              |
| 工具策略 | `ask`（默认，每次确认）/ `auto` / `off`                       |
| 操作     | 连接 / 断开 · 刷新工具列表 · 删除                             |

⚠️ **MCP 工具默认「每次确认」**，UI 上要明确说明这一点，
⚠️ **别让用户以为装了 MCP 就能「全自动」**。

## 4.6 记忆管理 `/settings/memory`

| 区域     | 内容                                                          |
| -------- | ------------------------------------------------------------- |
| 列表     | 内容 · 类型 · 来源 · 置信度 · 更新时间 · 被召回次数 · 操作     |
| 操作     | 编辑 · 归档 · 永久删除 · 新增                                  |
| 顶部     | 「自动记忆」总开关                                            |
| 底部     | 「永久清空全部记忆」（红色，二次确认）                         |

⚠️ **「归档」与「永久删除」要分清**：
归档 = 软删（不再被召回，但还能在 UI 里看到）；
永久删除 = 真删（用户行使「删除我的全部个人数据」的权利时要的是真删）。

## 4.7 通用配置 `/settings/general`

| 分组     | 项                                                       |
| -------- | -------------------------------------------------------- |
| 通用     | 语言 · 时区 · 工具步数上限 · 工具超时 · 工作区根目录    |
| 模型     | 默认温度 · 默认输出上限 · 思考预算 · 并行工具调用        |
| 记忆     | 自动记忆开关 · 相关性排序开关 · top K · token 预算 · 摘要开关 · 摘要预算 |
| 成本     | 月度 token 预算 · 是否硬拦 · 告警比例                   |
| 安全     | 允许内网出网 · Shell 开关 · 确认档位                    |
| 工具     | 输出截断长度 · 截断策略                                   |

⚠️ **分组是可折叠的**，每组顶部显示该组的说明。
⚠️ **boolean 项要有「清除覆盖」**（回到默认），⚠️ **不能只靠一个 on/off 开关** ——
用户没法表达「不要覆盖」。
⚠️ **工作区根目录改动要提示**：会改变文件工具能碰到的范围。

## 4.8 通用页面的共同要求

- 顶栏 + 面包屑（设置页之间要能跳转）
- 保存按钮在页面底部（长表单）且带 loading
- ⚠️ **保存失败要指到具体字段**，不弹一个笼统的 message
- 敏感值（API Key）永不回显
- 每个页面都有「说明」区（这个设置是干什么的）
