# 10 · 安全方案

> 本项目的安全边界**比一般 SaaS 更要紧**：Agent 能读文件、跑命令、发请求。
> 需求侧见 [12-e E4](./12-e-需求-观测安全与验收.md)，模块侧见 [07-f](./07-f-模块-安全与全栈.md)。

## 10.1 威胁模型

| 威胁                 | 来源                       | 后果                     | 对策                                       |
| -------------------- | -------------------------- | ------------------------ | ------------------------------------------ |
| **提示词注入**       | 文件 / 网页 / 工具返回内容 | 模型执行了不该执行的动作 | 工具结果标不可信 + 危险工具要确认          |
| **命令注入 / 误执行** | 模型生成命令              | 破坏本机数据             | 默认确认 + 黑名单 + 沙箱工作目录           |
| **路径逃逸**          | 模型传 `../../etc/passwd`  | 读到不该读的文件         | resolve（含 symlink）+ 沙箱判定            |
| **SSRF**             | 模型指定内网地址           | 探测内网 / 读云元数据    | 出网校验（私网 + 元数据 + 重定向逐跳）     |
| **密钥泄露**         | 日志 / 工具出参 / 错误栈   | 凭据外泄                 | 加密存储 + 打码 + 不返回堆栈               |
| **资源耗尽**         | 死循环 / 超大文件 / 高频调用 | 烧钱 / 占满磁盘       | 步数上限 + 单轮预算 + 工具超时 + 输出截断   |
| **供应链**           | 第三方 Skill / MCP server  | 任意代码执行             | 默认确认 + 安装提示 + 按 server 授权        |
| **端口暴露**         | 本机服务被局域网访问       | 未授权使用               | 默认只听 `127.0.0.1` + 登录                 |

## 10.2 边界划分

### 平台级（`.env`，用户改不了）

| 项                       | 默认            | 说明                                   |
| ------------------------ | --------------- | -------------------------------------- |
| `HOST`                   | `127.0.0.1`     | ⚠️ **默认只听本机**；要局域网访问再改   |
| `JWT_SECRET`             | 无              | **不配则启动失败**（不许用默认密钥）   |
| `CONFIG_ENCRYPTION_KEY`  | 无              | **不配则不许保存模型 key**             |
| `ALLOW_PRIVATE_EGRESS`   | `false`         | 允许指向私网的出网（要显式开）         |
| `COST_BUDGET_BLOCK`      | `false`         | 超预算是否硬拦                         |

### 用户可配（通用配置页）

`workspace_root` · `shell_enabled` · `tool_confirm_level` · `allow_private_egress` ·
`memory_enabled` · 预算类项

> ⚠️ **安全项不给「脱敏开关」**：脱敏是「写进历史库前的最后一道防线」，
> 能关就等于允许把身份证明文存库。
> ⚠️ 但**出网私网开关和 shell 开关是给用户的** ——
> 这两项本来就是「这台机器上我自己的机器」的决定，不是平台的安全承诺。

## 10.3 认证与会话

- bcrypt（cost ≥ 10）
- JWT HS256，默认 7 天
- **公开路由白名单**：`/api/v1/auth/login` · `/api/v1/health`
- `must_change_password` 账号只能访问 `/me` 与 `/change-password`（其余 403）
- 登录失败 5 次锁定
- ⚠️ **锁定响应体与「密码错」的响应体逐字段完全一致** ——
  不一致 = 告诉攻击者「这个账号存在」

## 10.4 文件系统安全

```
所有文件工具的路径：
  ① 规范化（resolve，⚠️ 含 symlink）
  ② 判是否在 workspace_root 内
  ③ 越界 → 明确报错
```

- ⚠️ **必须 resolve symlink** —— 只做字符串前缀判断的话，
  工作区里放一个指向 `/etc/passwd` 的软链就出去了
- ⚠️ **路径本身要查**：`../`、绝对路径、null 字节、超长路径
- 写文件默认要确认（`high` 档）
- **工作区根目录可配**，⚠️ 改这个配置要在 UI 上明确提示「会改变文件工具能碰到的范围」

## 10.5 出网安全

```
http_request：
  ① 协议只允许 http / https
  ② 解析目标域名 → IP
  ③ 判 IP 是否属私网 / 回环 / 链路本地 / 云元数据
  ④ 请求（带超时）
  ⑤ 遇到重定向 → 对新地址回到 ②（逐跳校验）
```

- 拒绝网段：`127.0.0.0/8` · `10/8` · `172.16/12` · `192.168/16` · `169.254/16` ·
  `::1` · `fc00::/7` · `fe80::/10`
- 云元数据：`169.254.169.254`（AWS/GCP/阿里云）· `metadata.google.internal`
- ⚠️ **DNS rebinding**：校验用的 IP 与实际连接的 IP 要一致
- ⚠️ **重定向逐跳校验** —— 只校验第一跳 = 换个 `Location` 就出去了
- 要指本机服务（本地 Ollama / 本地 MCP）→ 显式开 `allow_private_egress`

## 10.6 命令执行安全

- **默认「需确认」**（`high` 档）
- **黑名单直接拒绝**（不给确认的机会）：
  `rm -rf /` · `mkfs` · `dd if=` · `shutdown` · `reboot` · `:(){:|:&};:` · `curl | sh`
- 黑名单可扩展
- 超时杀进程（默认 30 秒）
- 工作目录固定在沙箱内
- ⚠️ **黑名单是兜底不是主防线** —— 主防线是「默认要确认」

## 10.7 提示词注入

| 层次       | 做法                                                            |
| ---------- | --------------------------------------------------------------- |
| **标注**   | 工具返回内容在回灌时明确标为「不可信数据，不能当指令执行」        |
| **隔离**   | 工具结果进 `tool` 角色，不进 system                              |
| **检测**   | 用户消息与工具结果过注入检测                                     |
| **处置**   | ⚠️ **命中只告警 + 收紧工具档，不直接拒答**（误报会让 Agent 变哑巴） |
| **兜底**   | 危险工具无论如何都要人确认 —— **注入检测失效也不至于出事**       |

> ⚠️ **最后一条是关键**：安全不能只靠检测。
> 检测是概率性的，**确认闸门是确定性的**。

## 10.8 密钥与数据

| 数据           | 处理                                                       |
| -------------- | ---------------------------------------------------------- |
| 模型 API Key   | AES-256-GCM 加密存储；不配 `CONFIG_ENCRYPTION_KEY` 不许存  |
| 密码           | bcrypt                                                     |
| 日志 / 流水    | 密钥类字段打码                                              |
| 工具输出       | 落库前截断；密钥类字段打码                                  |
| 对话内容       | 明文存本地（用户自己的机器）                                |
| 文件内容       | 不复制进 DB（只存路径与工具出参）                           |

> ⚠️ **`.env` 不进 git**；`.env.example` 里 secret 行留空

## 10.9 审计

写 `audit_logs` 的动作：

| action                 | 触发                                |
| ---------------------- | ----------------------------------- |
| `MODEL_CREATED/UPDATED/DELETED` | 增删改模型配置               |
| `PROMPT_PUBLISHED/ROLLED_BACK`   | 发布 / 回滚提示词          |
| `SKILL_INSTALLED/REMOVED`        | 装 / 卸 Skill                   |
| `MCP_ADDED/REMOVED`              | 接 / 断 MCP server                |
| `TOOL_ENABLED/DISABLED`          | 工具启停                          |
| `MEMORY_DELETED`                 | 删记忆                            |
| `WORKSPACE_ROOT_CHANGED`         | 改工作区根目录 ⚠️ 高危             |
| `SETTINGS_UPDATED`               | 改通用配置                        |

- ⚠️ **`details` 里绝不记密钥明文**
- ⚠️ **「用户点了批准」也要记**（谁在什么时候批准了哪个命令）

## 10.10 已知边界

- ⚠️ **本地项目没有网络隔离**：服务只听 `127.0.0.1`，但用户可能改成 `0.0.0.0`
  → 改成局域网暴露时，UI 上要提示风险
- ⚠️ **注入检测是概率性的**，不能当唯一防线
- ⚠️ **命令黑名单可被绕过**（编码、变量展开、别名）→ 靠确认闸门兜底
- ⚠️ **Skill 脚本 = 任意代码执行**，装之前用户要知情
- ❌ 不做内容 DLP（只管地址与密钥，不管业务内容）
- ❌ 不做端到端加密（本地单用户）
