# 04-b · UI · 登录页与聊天页

> UI 规格。写代码前先对这份。

## 4.1 登录页 `/login`

| 项           | 规格                                                          |
| ------------ | ------------------------------------------------------------- |
| 布局         | 居中卡片，宽 400px                                            |
| 标题         | 「Atlas · 登录」                                              |
| 副文案       | 「本地 AI Agent」                                            |
| 字段         | 邮箱 · 密码（≥ 8 位）                                        |
| 首次运行     | 无账号时表单切换为「首次使用，请创建本地账号」，标题变成「创建本地账号」 |
| 提交         | 按钮带 loading；失败在表单顶部显示错误文案（不弹 alert）       |
| 记住我       | **默认不勾选**（⚠️ 勾了才写 localStorage，不勾写 sessionStorage） |
| 忘记密码     | 留位文案 + 「请联系本机管理员重置」—— ⚠️ 本地单用户没有自助重置 |
| 深色模式     | 登录页**必须**支持深色（⚠️ 很容易漏，写死浅色 = 看不见）    |

> ⚠️ **「忘记密码」对本地项目是死路**：只有一个账号，没有「注册」也没有「找回」。
> 真正的重置路径是**删掉 `users` 表那一行重来**（见 [11](./11-部署运维与成本.md)）。
> UI 上要说清楚，别让用户点进一个空页面。

## 4.2 改密页 `/change-password`

| 项       | 规格                                                          |
| -------- | ------------------------------------------------------------- |
| 字段     | 原密码 · 新密码 · 确认新密码                                  |
| 校验     | 新密码 ≥ 8 位；两次一致；⚠️ **不能与原密码相同**             |
| 强制     | `must_change_password` 时**唯一可访问页**（其余 403）         |
| 成功     | 重新签发令牌并跳 `/chat`                                      |

## 4.3 聊天页 `/chat` ★

主界面。三块：会话栏（左）· 消息区（中）· 输入区（下）。

### 4.3.1 消息区

| 元素       | 规格                                                        |
| ---------- | ----------------------------------------------------------- |
| 用户气泡   | 右对齐，浅色底                                            |
| AI 气泡    | 左对齐，**不要拉满整行**（⚠️ 拉满 = 一大块空白，难读）    |
| 工具卡片   | 在对应消息**上方**，可折叠                                  |
| 待确认卡片 | 在对应消息**上方**，突出显示（这是要人做决定的）            |
| 时间戳     | 消息右上角小字；「今天」只显示 `HH:mm`                      |
| 引用块     | Markdown 渲染，蓝色左边线                                  |
| 代码块     | highlight.js 高亮 + 复制按钮（⚠️ 配色要跟深色模式切）      |
| 流式中的光标 | 尾部一个闪烁光标                                          |
| 空状态     | 没消息时显示欢迎语 + 几个建议问题（可配）                  |

### 4.3.2 输入区

| 元素       | 规格                                                          |
| ---------- | ------------------------------------------------------------- |
| 输入框     | 多行 textarea，`Enter` 发送 · `Shift+Enter` 换行              |
| 发送       | 空内容时禁用；发送中变成「停止」                              |
| 停止       | 调 `chat.stop()`；停止后已输出的内容保留                      |
| 重新生成   | 在**最后一条 AI 消息**上；⚠️ **必须传 `messageId`**           |
| 思考模式   | 勾选框「思考模式」→ 请求体带 `thinking`                      |
| 附件       | 本期不做（留位）                                              |

> ⚠️ **「重新生成」的坑**：不传 `messageId` 时 SDK 会重生成**最后一条**消息 ——
> 传错消息就重生了空气泡。必须 `regenerate({ messageId: msg.id })`。
> ⚠️ **顺带暴露的后端 bug**：SDK 重生成时会先把那条 assistant 从本地数组砍掉，
> 后端收到的末条是 user → 靠「末条是 assistant」判断**永远判错** →
> 后端要**按请求体的 `messageId` 定位**，不能靠「末条是什么」。

### 4.3.3 会话栏

| 元素       | 规格                                                        |
| ---------- | ----------------------------------------------------------- |
| 新对话     | 顶部按钮                                                    |
| 会话项     | 标题 + 相对时间；悬停显示「重命名 / 收藏 / 删除」          |
| 只看收藏   | 开关                                                        |
| 搜索       | 输入框（服务端搜）                                          |
| 折叠       | 窄屏自动折叠                                                |

> ⚠️ **切「只看收藏」不能掐断正在流式的回答**（见 [12-b B2](./12-b-需求-对话与编排.md)）。
> ⚠️ **自动发送不能在 mount effect 里直接调 `sendMessage`**（StrictMode + `chat.stop()` 会掐掉发送）。

### 4.3.4 工具卡片

| 状态     | 表现                                     |
| -------- | ---------------------------------------- |
| 执行中   | 旋转图标 + 「正在执行…」                |
| 成功     | ✓ + 工具名 + 耗时；出参默认折叠          |
| 失败     | ✗ + 工具名 + **错误原因**               |
| 已拒绝   | ⊘ + 「用户已取消」                       |
| 待确认   | 橙色 + 「批准 / 取消」两个按钮 + 参数预览 |

> ⚠️ **失败必须显示原因**，不能吞掉 —— 用户要能判断是工具坏了还是模型用错了。
> ⚠️ **入参出参里的密钥要打码**。

### 4.3.5 待确认卡片

- 明确写出**要执行什么、影响什么**（不是只给一串参数）
- 两个按钮：**批准**（主）/ **取消**（次）
- ⚠️ **批准按钮要有 loading**（执行可能要几秒），避免重复点击执行两遍
- ⚠️ **批准后模型改了参数 → 要重新弹确认**（不能沿用旧的批准）

## 4.4 消息级收藏 📌

- 每条 AI 消息右上角一个 📌
- 收藏状态存 `messages.favorite`
- 「只看收藏」筛选同时看会话级与消息级

> ⚠️ **不写审计**（跟会话级收藏一致）—— 收藏是个人偏好，不是管理动作。

## 4.5 会话历史页 `/sessions`

- 表格：标题 · 消息数 · 最后活跃 · 工具调用数 · 收藏 · 操作
- 搜索 + 只看收藏筛选（**服务端筛**）
- 批量删除（带二次确认）
- ⚠️ **「总数」卡要显示筛选后的数量**（⚠️ 常见 bug：卡上写总数、筛选后不变）
