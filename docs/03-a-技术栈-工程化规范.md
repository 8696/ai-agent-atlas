> ⚠️ **`ai` / `@ai-sdk/react` 的用途收窄了**：
> Atlas 的**模型调用走 LangChain 的 ChatModel**（LangGraph 要的就是这个接口），
> AI SDK 在本项目里只负责**前端消息流协议**（`useChat`）——
> 后端要把 LangGraph 的事件翻译成 AI SDK UI Message Stream。
> 见 [03-b §B.6](./03-b-技术栈-后端栈.md)。
> **不要**在后端用 `streamText` 起第二套模型调用路径 —— 那会出现「两套流式栈」，
> 是这个项目最容易踩的坑。

### A.9 环境变量校验（启动时挂）

- 所有环境变量走 **zod schema**（`src/config.ts` 里的 `envSchema`）
- **启动时校验，失败直接退出并打印缺哪个 key**
- ⚠️ **`.env` 和 `.env.example` 是同一份东西的两副面孔**：同一组 key、同一顺序、同一段注释，
  **只有值不同**（`.env` 写真值 / `.env.example` 留空）
- 「哪个 key 该存在」的唯一依据 = `envSchema`
- 改了 `envSchema` 必须同步两个文件，并跑 `yarn env:check`（漂了退出码 1）
- 兜底测试 `tests/unit/env-consistency.test.ts` 守着同一套不变量

**本项目的 key 分组**（详见 [11](./11-部署运维与成本.md)）：

| 组            | 典型 key                                                     |
| ------------- | ------------------------------------------------------------ |
| 服务          | `PORT` / `NODE_ENV` / `HOST`                                |
| 存储          | `DATABASE_PATH` / `VECTOR_DB_PATH` / `WORKSPACE_ROOT`        |
| 模型（平台默认） | `LLM_PROVIDER` / `LLM_BASE_URL` / `LLM_API_KEY` / `LLM_MODEL` |
| 安全          | `JWT_SECRET` / `CONFIG_ENCRYPTION_KEY` / `ALLOW_PRIVATE_EGRESS` |
| 预算          | `DEFAULT_TOKEN_BUDGET` / `COST_BUDGET_BLOCK`                 |
| 日志          | `LOG_LEVEL`                                                   |

### A.10 错误处理约定

- 业务错误 → 抛 `AppError`（带 `code` / `status` / `message`）
- **模型与工具能读懂的错误必须转成文本回灌给模型**，
  而不是让整轮 500 —— 用户看到的是「工具失败了，原因 X」，不是白屏
- gateway 层统一把错误映射成 `{ error: { code, message } }`
- ⚠️ **不要把栈信息返回给前端**（生产模式）

### A.12 目录约定（barrel exports）

- 每个目录一个 `index.ts`，对外只暴露 `index.ts` 里的东西
- **禁止跨目录深引用**（`import ... from '../tools/builtin/shell/impl'` 这类）
  —— 目录结构一改就全炸

### A.13 测试约定

| 层            | 放哪                    | 特点                                                       |
| ------------- | ----------------------- | ---------------------------------------------------------- |
| **unit**      | `tests/unit/`           | 纯函数，无 DB、无网络；LLM 与向量调用一律 mock             |
| **integration**| `tests/integration/`    | 真 SQLite 临时库；模型调用 mock（**零费用**）               |
| **e2e**       | `tests/e2e/`            | Playwright，真浏览器                                        |

- ⚠️ **集成测试绝不能真调 LLM**（一次调用就是钱）——
  `vi.mock` 掉模型与向量模块，测试断言的是**编排行为**，不是模型输出
- 每个集成测试文件负责建表 / 清理，不共享状态

### A.14 antd v6 迁移注意（写前端前先看）

| 旧写法（v4/v5）     | v6 写法                        |
| ------------------- | ------------------------------ |
| `<Alert message>`   | `<Alert title>`                 |
| `<Space direction>` | `<Space orientation>`           |
| `destroyOnClose`    | `destroyOnHidden`               |
| `<Drawer width>`    | `<Drawer size>`                 |
| `<Modal maskClosable>` | `<Modal maskClosable>`（仍支持，但确认是否还在废弃列表） |

- 兜底守卫：`tests/unit/antd-deprecated-props.test.ts`（静态扫源码，
  **组件在不在页面上、抽屉开没开都算**）+ `tests/e2e/antd-deprecation.spec.ts`（真开浏览器看控制台）
