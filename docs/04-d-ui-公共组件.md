# 04-d · UI · 公共组件与错误页

> UI 规格。写代码前先对这份。

## 4.1 公共组件清单

| 组件              | 位置                 | 作用                                                   |
| ----------------- | -------------------- | ------------------------------------------------------ |
| `<ErrorBoundary>` | `web/components/`    | 最外层错误兜底（React 渲染异常 try/catch 接不住）      |
| `<RequireAuth>`   | `web/components/`    | 路由守卫（重定向 + 401 处理）                          |
| `<Markdown>`      | `web/components/`    | 代码高亮 + 复制按钮 + 引用块 + 链接新窗口 + 深色适配   |
| `<Chart>`         | `web/components/`    | ECharts 封装（把 antd token 合进 option）             |
| `<ErrorPage>`     | `web/pages/`         | 403 / 404 / 500 专门文案                              |

> ⚠️ **`ErrorBoundary` 挂在 `main.tsx` 最外层**，
> 但 ⚠️ **React Router v7 自带的内部错误边界比它更靠近路由组件** ——
> 路由里渲染炸了，用户看到的是 RR 的**默认英文页 + 堆栈**，
> 外层那个根本轮不到出场。
> → **每条路由都要挂 `errorElement: <ErrorPage />`**（见 [03-c §C.3](./03-c-技术栈-前端栈.md)）。

## 4.2 `<Markdown>` 规格

| 特性       | 要求                                                       |
| ---------- | ---------------------------------------------------------- |
| 代码高亮   | highlight.js；⚠️ **配色必须跟深色模式切**（两套主题）      |
| 复制按钮   | 代码块右上角；成功给 `message.success` 反馈               |
| 引用块     | 蓝色左边线 + 浅色底                                        |
| 链接       | 新窗口打开（`target="_blank" rel="noopener noreferrer"`）  |
| 表格       | GFM 表格支持；窄屏横向滚动                                 |
| ⚠️ 安全    | **禁用原始 HTML**（`rehype-raw` 不装）—— 防止 XSS          |

> ⚠️ **禁用原始 HTML 是硬要求**：模型输出 / 工具输出都可能带 HTML，
> 开了 raw 就等于开一个 XSS 口。

## 4.3 `<Chart>` 规格

- 统一封装 ECharts，**把 antd token 合进 option**（`notMerge` 恒开）
- ⚠️ **不能指望 ECharts 自己 merge** —— 不显式传色，坐标轴刻度会用默认色
- ⚠️ **深色模式下坐标轴刻度必须可读**：
  ECharts 默认 `axisLabel` 色是写死的浅灰（`#54555a`），
  深色卡片底（`#1f1f1f`）上**对比度只有 2.2:1**（AA 要 4.5:1）→
  深底上只看得见网格线、看不见刻度
- 统一封：轴线色 · 网格线色 · tooltip 底色 · 图例色 · 提示线色
- 空数据：显示「暂无数据」而不是一张空图

## 4.4 错误页

| 状态 | 路径             | 文案要点                                   | 操作         |
| ---- | ---------------- | ------------------------------------------ | ------------ |
| 403  | `/{scope}/403`   | 「没有权限」                               | 返回上一页   |
| 404  | `/{scope}/404`   | 「页面不存在」                             | 回首页       |
| 500  | `/{scope}/500`   | 「服务异常，已记录」                       | 重试 + 回首页 |
| ⚠️ 全局 | `*`            | 未知路径 → 404                             | —            |

- ⚠️ **500 页不要显示堆栈**（生产模式），但要显示 **request id**，
  方便用户报障时定位
- ⚠️ **文案里不要出现英文原始错误**（如 `Forbidden`、`Internal Server Error`）
  —— ⚠️ **错误文案只能有一个实现**（`lib/apiError.ts`），
  各 api 模块各抄一份 `errorMessage` 是错误文案的常见事故源

## 4.5 公共约定

- **不用 CSS 预处理器**；自定义样式用 CSS Module 或 token
- 图标只用 `@ant-design/icons`
- 所有异步按钮有 loading 态并禁用重复提交
- 所有列表页都有 加载中 / 空 / 出错 / 正常 四态
- 所有破坏性操作有二次确认
- 键盘可达 + 焦点可见 + 颜色不是唯一信息载体
