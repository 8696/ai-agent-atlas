## 模块 14 · 本地边界（无鉴权）

**职责**：**没有鉴权模块** —— 本期服务免鉴权（见 [12-a A1](./12-a-需求-应用外壳与上下文.md)）。

**替代的边界措施**：

- **默认只监听回环地址**（`HOST=127.0.0.1`）—— 局域网访问不到
- `HOST` 改成非回环 → **启动时红色告警**，说清「局域网内任何人都能执行命令」
- CORS 只允许本机来源
- ⚠️ **无鉴权**：没有账号、没有 JWT、没有登录失败锁定 —— 这套攻击面直接不存在
- ⚠️ **审计更重要**（没有账号就不知道谁干的）：
  工具调用 / 配置变更 / 记忆删除全部留痕

**已知边界**：

- ❌ 不做注册 / 登录 / 找回密码（本期无鉴权）
- ❌ 不做多因素
- ❌ 不做 API Key（对外开放时才需要 —— 而本期默认不对外开）
- ⚠️ **服务一旦开在非回环地址 = 局域网内任何人都能用它执行命令**，
  这是「无鉴权」的代价，靠默认配置（`HOST=127.0.0.1`）兜住

## 模块 15 · 工具安全闸

**职责**：决定「这个工具调用能不能执行 / 要不要人确认」。

**判定四档**：`allow` · `await` · `blocked` · `reject`

**判定输入**：工具敏感档 · 全局确认档位 · 硬禁配置 · MCP server 策略 · 命令黑名单

**关键约束**：

- ⚠️ **MCP / Skill 来源的工具默认 `await`** —— 第三方代码不能自动执行
- ⚠️ **命令黑名单命中 → `blocked`**（直接拒绝，**不给确认的机会**）
- ⚠️ **策略模块出错 → 按最严的一档（`await`）** ——
  ⚠️ **绝不能 fail-open**（出错就放行 = 闸门形同虚设）
- 黑名单可扩展（代码常量）
- ⚠️ **三个高危工具有额外约束**（不靠黑名单，靠各自的边界）：
  | 工具           | 额外约束                                             |
  | -------------- | ---------------------------------------------------- |
  | `browser`      | 只能访问域名白名单；默认 `await`                     |
  | `execute_code` | 默认**无网络**；受限子进程；默认 `await`             |
  | `delete_path`  | 路径必须完全落在工作区内；**工作区根目录本身不可删** |
- ⚠️ **子代理与定时任务走同一道闸** —— 定时任务唯一例外是显式声明的 `autoApprove` 白名单

**降级**：黑名单文件读不到 → 用内置默认黑名单（**不是空黑名单**）。

**已知边界**：

- ❌ 不做命令的语义分析（只做模式匹配）
- ❌ 不做「这次批准了以后都批准」

## 模块 16 · 出网与路径安全

**职责**：文件工具的路径沙箱 + HTTP 工具的出网校验。

**关键约束**：

**路径沙箱**

- 先 `resolve`（⚠️ **含 symlink**，否则软链能绕出去）再判断是否在工作区内
- 工作区根目录可配（⚠️ 在 `.env` 的 `WORKSPACE_ROOT`，因为它跟机器相关），默认 `data/workspace/`
- 越界 → **明确报错**（不是静默失败，也不是截断成相对路径）
- ⚠️ **路径本身也要查**（`../`、绝对路径、符号链接、null 字节）

**出网校验**

- 只允许 `http` / `https`
- ⚠️ **解析目标 IP → 拒私网 / 回环 / 云元数据地址**
  （`127.0.0.0/8` · `10/8` · `172.16/12` · `192.168/16` · `169.254/16` · `::1` · `fc00::/7`）
- ⚠️ **重定向要逐跳校验** —— 只校验第一跳 = 换个 Location 就出去了
- ⚠️ **DNS rebinding**：校验用的 IP 与实际连接的 IP 要一致
- 生产默认禁私网；指本地服务要显式放行（`allow_private_egress=true`）
- `file://` / `gopher://` 等一律拒绝

**沙箱执行（`execute_code`）**

- ⚠️ **不能用 Node 的 `vm` 模块** —— `vm` 不是安全边界（能拿 `require` 就等于拿到系统）
- 必须用**受限子进程**：不传 `NODE_OPTIONS` · 不继承敏感环境变量 · `cwd` 限制在工作区 ·
  超时**强杀整个进程组** · 默认无网络
- ⚠️ **在代码注释里写明**：这是防「模型手滑写出破坏性脚本」的护栏，
  **不是**防有人故意投毒的强隔离
- 脚本里的 RPC 工具调用**同样走权限闸**

**降级**：DNS 解析失败 → 拒绝出网（不是「解析不了就放行」）。

**已知边界**：

- ❌ 不做内容级的出网过滤（只管地址，不管返回什么）
- ❌ 不做代理支持
